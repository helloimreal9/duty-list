# Список дежурных — общая версия

## Что внутри
- Общий список группы с синхронизацией через Supabase Realtime.
- История отметок: имя, действие, дата и время, номер круга.
- Автоматический переход на следующий круг после отметки всех 24 человек.
- Ручной сброс текущих отметок без удаления истории.
- Поиск по списку.

## 1. Создайте проект Supabase
1. Откройте https://supabase.com/ и создайте бесплатный проект.
2. В проекте откройте **SQL Editor → New query**.
3. Откройте файл `supabase_setup.sql`, скопируйте весь SQL и нажмите **Run**.
4. Откройте **Project Settings → API** (или **Connect**) и скопируйте:
   - Project URL
   - `anon` / `publishable` key (публичный ключ)

**Никогда не используйте `service_role` / `secret` key в HTML.**

## 2. Подключите сайт к базе
В `index.html` найдите в начале JavaScript:

```js
const SUPABASE_URL = "";
const SUPABASE_ANON_KEY = "";
```

Вставьте значения между кавычками, например:

```js
const SUPABASE_URL = "https://ВАШ-ПРОЕКТ.supabase.co";
const SUPABASE_ANON_KEY = "ВАШ-ПУБЛИЧНЫЙ-ANON-ИЛИ-PUBLISHABLE-KEY";
```

Сохраните файл. Публичный ключ допустимо использовать в браузере только вместе с настроенными ограничениями RLS, которые создаёт SQL-скрипт.

Можно вместо этого открыть сайт и заполнить блок **«Подключение общей базы → Настроить»**. Такой способ сохранит ключ только в конкретном браузере, поэтому для других участников настройку придётся повторить. Для общего опубликованного сайта удобнее вписать URL и ключ в `index.html` до загрузки в GitHub.

## 3. Опубликуйте на GitHub Pages
1. Создайте репозиторий GitHub, например `duty-list`.
2. Загрузите `index.html` и `supabase_setup.sql` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`, нажмите **Save**.
6. Дождитесь публикации. Сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/duty-list/`.

## 4. Важные замечания
- Все участники, открывшие одну и ту же ссылку, видят общие отметки и историю.
- Синхронизация работает при подключённом интернете.
- История хранит последние 500 записей на странице (старые записи остаются в базе).
- Сейчас доступ к просмотру и отметкам открыт всем, у кого есть ссылка. Это удобно для группы, но не является защитой от посторонних. Если нужна защита, можно добавить вход по паролю или авторизацию.
- Список имён в SQL-функции и HTML должен совпадать. При изменении состава группы обновите оба места.
